〇 整体图景:两层各自回答一个问题

整套机制分两层。组网层回答"谁知道什么"——哪些导弹连得回舰队、谁在回传、谁断链只剩自己;行为层(三关系算法)回答"怎么飞"——多股导弹怎么自己并成一团、同刻弹着,同时谁也不把油烧干。两层完全解耦:组网断了,三关系照样在弹与弹之间生效,因为它的输入只有邻居、到目标的距离和自己的油——不依赖舰队。

一 组网层:链路、在线、回传

每个感知节拍(1 游戏秒),mslNetStep 对蓝红各做一遍:

1) 建邻接。把本方所有活着的导弹组两两配对,中心距小于 8.775 万 km(弹弹通信距离,MSL_LINK.MM)就连一条边,彼此记进对方的邻接表 p.nb。布了雷的、飞向布雷点的也算——它们同样是中继节点。这是 O(n²) 的距离检查,几百组以内每秒一次毫无压力。

2) 判在线。再看弹到本方舰船 / 前出浮标的距离,小于 9 万 km(弹舰距离,MSL_LINK.MS)的组标记"直连舰队";然后从这些直连组出发,沿弹弹边做宽度优先扩散——扩散到的都算在线。也就是说:一簇导弹只要有一组够得着任何一艘舰,整簇都在网上。

3) 在线的义务与权利。在线的组每拍把自身状态(位置、剩几枚、剩多少油、在追谁)回传舰队,画面上按真实位置画,选中面板照实报;同时有资格收舰队的数据链引导(火控通道喂目标估计位置,通道数有限,54 的 guideSide 分配)。刚断链的那一拍,按最后一次回报建一条"推测弹标"沿程序外推,直到重新上网、被看见、或推出游玩区才撤。

4) 断链的降级。断链的组不再读目标死活、不再翻舰队航迹表,只靠发射时带的和沿途更新的那份目标记录飞;导引头看得见原目标的照追,另锁新目标的走默认规则(按体型相似度挑,详见断链备忘)。这一层的详细规则在"导弹组网(二)"那次提交里,本文不展开。

二 三关系算法:每枚导弹每拍只读三样东西

这是最终形态(2026-10-02,间距 2 万 / 聚合力 0.7)。没有集结点、没有槽位、没有簇级计算——每枚导弹、每个仿真步,只读邻居(位置和油)、自己到目标的距离、自己的油,在 mslSwarmStep(①③)和 mslSwarmVc(②)两个函数里算出这一拍的航向和速度指令。

① 自身油量 → 能力天花板

aC = min( vPeak, vTerm + (油 − 2 秒冲刺预留) × 加速度 )

油烧得越多,天花板越低——谁也不可能被要求飞出自己油量允许的速度。vPeak 在发射时算好,带"整箱油预算":加速占一半((FUEL·0.75·ACC + vTerm)/2),没有这条预算的话天花板只留 2 秒预留,会把全员放到过度加速、20 秒烧空(实测过)。保底 vTerm 保证转弯机动始终够用。

② 目标距离 + 一跳邻居 → 同步

先算有效路程:dEff = 到目标距离 + 0.5 × 离局部质心的距离——要并团就得走弯路,调度不能按直线自欺。然后与一跳邻居(邻接表里同目标的组)比到达时刻,注意用的是按能力天花板算的 eta,不是按当前速度:

etaRef = max( dEff/aC, max over 邻居 (dj / aC邻居) )
vCmd = clamp( dEff / etaRef, 0.85·aC, aC )  // 等最慢的;等不起(低于下限 15%)就掉队
只在 |vCmd − 旧指令| > 3% 时才执行  // 调度滞回,不为噪声重新加减速

油多的新弹 aC 高、eta 小、自己会追,别人不必傻等;油烧多的领先弹 aC 低、eta 大,全簇适当放慢等它——"照顾弱者"从公式里自然长出来,而 0.85 下限保证等不起时宁可分队弹着,绝不爬行。一跳一跳传播就够了:信息沿链自然扩散,不需要全簇泛洪。

③ 邻居 → 聚拢(航向)

dir = norm( 目标方向 + COH·fadeT·fadeC·质心方向 + 0.8·fadeT·排斥向量 )

质心吸引把散开的弹道拢成一团,权重随离质心的距离衰减(fadeC)——已经收拢的不再拉,转向油只花在还没并进来的弹上;间距排斥在比 2 万 km(间距 S)近时互推,不叠在一起;2° 转向死区不追微小抖动。整个聚集力距目标 2.5 万起、在 12.5 万带内线性淡出(fadeT),接近目标后只剩目标牵引。

三 两段式飞行:会合可微减速,冲刺绝不减速

速度指令分两段(2026-10-01 拍板"饱和攻击两段式")。会合段即上面 ② 解出的同步巡航:尾随的顶天花板追,领先的最多减到 0.85×天花板——"稍微减速收队",绝不刹车爬行。冲刺段在距目标 3 万 km(= 导引头主动锁定范围,恰好盖过近防外圈 1.875 万)生效:不再减速,保持进入速度带速命中,上面的刹车曲线与燃料安全帽一并不管——冲刺不需要留刹车的油,意义是缩短在近防圈里的暴露时间。

燃料总账:每枚导弹一生只烧三笔油——一次加速到排定速度、聚拢修正的转向、终端冲刺。巡航本身免费。

五 演化史与踩过的四个退化点

最终形态不是一次设计出来的,四代方案每个都留下一条硬教训:

第一代 · OFF_L 固定包抄(v121 遗产)

发射时按组序摆好"直插 / 上翼 / 下翼"三个方向,侧翼 +12% 配速。问题:只认同一次齐射,多波之间毫无关系——用户在靶场看到"三波还是三波"。

第二代 · 翼面槽位(冻结不重排)

一个连通簇 = 一面翼,槽位按入列次序左右交替。两个坑:

退化点一 · 槽位不认边

槽位按入列次序分配,下面舰的弹会被分到上面的翼尖——整组横穿编队过去,转向油翻倍,烧到只剩 8/45,被燃料安全帽钉死在最低速爬行,掉队 25 秒。修法:槽位左右跟组所在的那一侧(后来干脆随槽位一起删掉)。

退化点二 · 按距离重排槽位

槽位按当前离轴距离每拍重排,超车的一瞬间左右互换,弹道来回横穿白烧转向油。修法:槽位在入列那一刻冻结。

第三代 · 显式集结点

簇心→目标连线上、距目标 10 万处取一个集结点,各组先飞"集结点 + 槽位"再转冲刺。弹着窗最好看(1.6 秒),但用户指出方向性问题:

设计转折 · 集结点必须自然涌现

"集结点不是显式指派的,而是导弹-导弹 / 导弹-目标聚合算法自然实现的。"于是拆掉集结点和全部槽位,换质心吸引 + 间距排斥——并团反而更早更紧(105 秒就收到 ±1.4 万)。

第四代 · 三关系(最终)

退化点三 · 分离力持续抖动

紧密编队里人人都被排斥力推着,航向每拍微抖,微转向不停烧油——每组各有一枚被耗到油 18%、掉队 25 秒(弹着窗 32 秒)。修法:分离半径收窄、权重减半、加 2° 转向死区。

退化点四 · 按当前速度算同步(最隐蔽)

同步参照一开始用邻居当前速度的到达时刻:最慢的一组 eta 最大,人人等它,全体滑到 0.85 减速下限、1586 均速齐飞——所有组同速,距离差永远冻结,弹着窗 18 秒。改成按能力天花板算 eta 后立刻收敛到 1.9 秒。教训:同步要比"能跑多快",不能比"现在跑多快"。

附带教训 · 平滑的方向性

同步锚点 T 的平滑滞后会刹住最前面那组(它定义 T,T 缩小时滞后值比它大,指令让它减速)。修法:平滑只在 T 变大的方向起作用,缩小即时跟。

六 打空地、断链、与舰队的分工

打空地。区域齐射的弹走"飞向布雷点"分支,三关系抽成公共函数(mslSwarmStep / mslSwarmVc)后同样生效:目的地 = 布雷点,同片 6 万内的邻组一起同步聚拢——三舰对同一点各射一组,±3.5 万的散布 40 秒后收到 ±0.8 万。瞄不同点(相距 6 万以上)的弹互不组网,各飞各的,这是有意的。

断链。三关系的输入全在弹上(邻接表每拍重建、距离自己量、油是自己的),断链只影响"回传显示 + 数据链引导"两件事,聚集与同步照常。画面上选中一枚导弹,能看到它所在连通簇的最小生成树链路,够得着舰就多一段亮线——那是组网层的直读。

与舰队的分工。舰队只做一件事:指派目标(火控序列沿数据链传导)。怎么飞、什么时候到、跟谁并团,全部是弹与弹之间的事——这正是"组队逻辑只针对导弹-导弹"的边界。

function mslNetStep(dt){
  mslNetT+=dt;if(mslNetT<SENS.TICK)return;mslNetT=0;
  const MS2=MSL_LINK.MS*MSL_LINK.MS,MM2=MSL_LINK.MM*MSL_LINK.MM;
  for(const side of ['blue','red']){
    const F=[];for(const s of ships)if(s.side===side&&!s.dead)F.push(s.pos);for(const o of rockObjs())if(o.kind==='buoy'&&o.side===side&&!o.dead)F.push(o.pos);
    const M=projectiles.filter(p=>p.type==='missile'&&!p.done&&p.shooter&&p.shooter.side===side),q=[],was=M.map(p=>p.online!==false);
    for(const p of M){p.online=false;for(const f of F){const dx=p.pos[0]-f[0],dy=p.pos[1]-f[1],dz=p.pos[2]-(f[2]||0);if(dx*dx+dy*dy+dz*dz<MS2){p.online=true;q.push(p);break;}}} // 直连舰队
    for(let i=0;i<q.length;i++){const a=q[i];for(const b of M){if(b.online)continue;const dx=a.pos[0]-b.pos[0],dy=a.pos[1]-b.pos[1],dz=a.pos[2]-b.pos[2];if(dx*dx+dy*dy+dz*dz<MM2){b.online=true;q.push(b);}}} // 经弹弹链接力
    M.forEach((p,i)=>{if(p.online){mslRep(p);if(p.pg)mslPredDel(p.pg);}else if(was[i]&&!p.pg&&p.rep)mslPredAdd(p,'msl');}); // 在网上每拍回报;刚断链按最后一次回报建推测
    for(const p of M)p.nb=[]; // 邻接:三关系算法的"导弹间关系"输入(所有活弹,含雷 / 布雷途中 —— 它们也是中继节点);MM2 用上面直连 / 接力那两个同款
    for(let i=0;i<M.length;i++)for(let j=i+1;j<M.length;j++){const g=M[i],q=M[j],dx=g.pos[0]-q.pos[0],dy=g.pos[1]-q.pos[1],dz=g.pos[2]-q.pos[2];
      if(dx*dx+dy*dy+dz*dz<MM2){g.nb.push(q);q.nb.push(g);}}
    for(const p of projectiles)if(p.type==='mac'&&!p.done&&!p.pg&&p.shooter&&p.shooter.side===side)mslPredAdd(p,'mac'); // 炮弹:出膛状态本来就知道,直线外推
  }
  mslPredStep();
}

function mslPredPos(g,now){ // 推测记录此刻在哪
  const u=now-g.t;
  if(g.k==='mac')return [g.pos[0]+g.vel[0]*u,g.pos[1]+g.vel[1]*u,g.pos[2]+g.vel[2]*u];
  if(g.mine)return g.pos.slice();
  const s=g.spd*u;
  if(g.aim){const dx=g.aim[0]-g.pos[0],dy=g.aim[1]-g.pos[1],dz=g.aim[2]-g.pos[2],d=Math.hypot(dx,dy,dz)||1;
    if(s<d)return [g.pos[0]+dx/d*s,g.pos[1]+dy/d*s,g.pos[2]+dz/d*s];
    if(g.mineOk)return g.aim.slice();
    return [g.aim[0]+dx/d*(s-d),g.aim[1]+dy/d*(s-d),g.aim[2]+dz/d*(s-d)];}
  return [g.pos[0]+g.dir[0]*s,g.pos[1]+g.dir[1]*s,g.pos[2]+g.dir[2]*s];
}

  const nb=[]; // 同目的地的邻组:追目标 = 同一目标;打空地 = 布雷点在同一片(6 万内)
