# FM5 编队书签 UI 重做(书签仪表化 + 轻菜单三级层次)+ 实时视觉迭代

## 已确认的决策
- 方向 B:**书签仪表化**——书签本身变成小仪表(状态色条 + 迷你HP条 + 数量);点开的菜单仍是纯操作,重排为三级视觉层次(模式主操作 / 编队行动次操作 / 危险操作)。**实时数据分工不变**(仍在右栏 #selFm,选中编队时显示)。
- **点书签 = 选中全队 + 展开菜单**(再点同一书签收起菜单、选中保留)。
- 实时迭代方式:我在真实浏览器里跑游戏,每轮改动后刷新截图给你看,你随时可插话改方向(本次规划中已验证此循环可行)。

## 现状与问题
- 书签(`#fmBar`):状态只编码在 3px 色条 + title 提示里,无 HP/战力感知。
- 菜单(`#fmMenu`):书签右侧 130px 处的一摞 44px 等宽文字按钮,模式三选与跟随/停车/解散视觉权重完全相同,层级靠 title 提示撑着。
- 工作树有一份**未提交的 FM4b 菜单重排**(87-fmbar.js,36+/61-,已完成的重排:模式置顶/随模式显隐块/底部固定区)——本次工作直接在它之上进行。

## 实施步骤

**第 0 步 · 收底 FM4b**
跑 `tools/verify.sh` 确认全绿(探针若有引用已删按钮的 FLOW,按当前 UI 契约修正探针),把工作树里的 FM4b 重排单独提交,再开始 FM5。

**第 1 步 · 书签仪表化**(js/render/87-fmbar.js fmbTabs + css/app.css)
- 书签结构:`[3px状态色条][舰名(flex省略)][N艘(等宽)]` + 底部**3px 全宽聚合 HP 条**(宽度/颜色口径抄现有 hpbar:>35% 绿 / 否则橙,fmbStat 已有 hpFrac)。
- 只改叶子 textContent/style/class;**编队集合不变就不重建 DOM**(既有守卫,HP 条同样只写叶子)。
- 书签宽度上限保持 ≤110px(#fmMenu 的 left:calc(--gut+120px) 依赖它,不动菜单定位)。

**第 2 步 · 菜单三级层次**(fmbActsBuild/fmbActsSync + css)
- 标题行(编队1 + N艘·固定态)保持不动。
- **一级·模式**:固定/阵型/跟随做成**连体分段控件**(segmented,当前段点亮),下压一行暗色模式说明(复用 fmbModeText 长文案,单一出处)。
- **二级·编队行动**:随模式显隐块(固定→重拍队形 / 阵型→编组控制 / 跟随→空) + 跟随目标/解除跟随 + 整队停车,维持 grid 定列。
- **三级·危险区**:发丝线分隔后,解散编队(红描边 .qstop)独占底部。
- 所有 data-fma id 不变(m-fixed/m-slot/m-follow/resnap/page/fol/folx/halt/disband),事件委托零改动;新增 .fm-seg/.fm-mdesc/.fm-sec 样式全部走 :root token,零新色号、零 emoji。

**第 3 步 · 点书签 = 选中并展开**(fmbToggle)
- 展开:fmUi.open=g;`selected=fmShips(F) 成员 id` + fmbRefreshSel()(清导弹选中态、唤醒右栏/底栏)+ 日志"N 艘 → 选中编队X"。
- 收起(再点同一书签):只收菜单,选中保留。切换到另一支编队的书签:菜单与选中同时切过去。
- 数字键 1-4 选中编队、双击跳镜头等既有键位不动。

**第 4 步 · 探针 + 文档 + 发版**
- verify.sh 增补 FM 检查:模拟 #fmBar pointerdown → 断言菜单展开且 selected 恰为该编队成员;书签 HP 条与状态类同步正确。
- CLAUDE.md 记 FM5 备忘与验证记录;index.html 的 css/js `?v=` 缓存号统一升级一次。
