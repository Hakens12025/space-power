# 简化 UI 改造方案（RF2：选中舰面板 + 底部操作栏）

## 已确认的决策

移动保留现有右键方式；**只藏 UI 不删逻辑**（所有 DOM 元素留在 HTML、全部 39 个 js 照常加载，仅 CSS 隐藏 + 个别入口早退）；多选时底部操作对全选生效、信息栏显示第一艘选中舰；事件反馈内嵌右栏；点敌舰无操作；adminMode 保持默认 true；**底栏开关用纯文字标签，不用 emoji**。

开关按钮 = 纯中文标签 + 「·开/·关」后缀，状态同时用现有 `.on` 类着色（开=强调蓝底边、关=灰暗），无任何 emoji。

## 文件级改动清单

**新增 `js/render/88-selpanel.js`**（约 180 行，插到 index.html render/87 之后）：
- `updateSelPanel()`：刷新右栏——舰名/舰种·Tier、HP 条+数值、锁定目标+距离、主炮冷却（就绪/倒计时）、导弹就绪单元 x/y + 弹药、拦截弹库存、速度；多选时标题"已选 N 艘"，无选中显示提示文案
- `updateCmdBar()`：五个开关按钮的标签后缀（·开/·关）与 `.on` 类；无选中时 `.is-dis`
- 开关语义（全部作用于所有选中蓝舰，统一置为目标态）：
  - **火控** = 读 `autoEngage`；开→`autoEngage=true,roe='free'`，关→`autoEngage=false,roe='hold',lockedTarget=null`
  - **雷达** = `s.lidar`
  - **主炮/导弹/拦截** = 新字段 `macOn/mslOn/ciwsOn`
- hover：设全局 `hoverRing`（'mac'/'msl'/'ciws'）+ 显示 `#cmdTip`（射程/伤害/装填/库存的纯文字说明）；移开清除
- `pushEvt(msg,cls)`：最近 5 条事件环形数组 → 渲染 `#selEvents`（事件文案沿用现有 log 字符串，其中的符号属模拟层消息，不在本次改动范围）

**`index.html`**：加 `#selPanel`（右轨，class="panel"）、`#cmdBar`（底坞居中）、`#cmdTip`（悬浮提示）三块 DOM + `render/88` script 标签。**不删任何现有元素**。

**`css/app.css`**（RF2 节，约 60 行）：
- 隐藏（`display:none!important` 防 applyPanelState 内联样式覆盖）：`#qbar #fleet #log #scenePanel #trPanel #editorPanel #replayBar #overlay #specView #ringPanel #statusTip` + 顶栏 `#btnRec #btnAdmin #btnSelfPlay #btnRange #btnEnv #btnReplay #btnSet`
- 新样式：`#selPanel` 抄 `#fleet` 的右轨定位规则；`.hpbar` 血条；`#cmdBar` 仿 `#qbar` 底坞；开关钮复用现有 `.btn` 基座 + `.on` 开启态；`#cmdTip` 绝对定位在底栏上方

**`js/core/01-state.js`**：+`let SIMPLE_UI=true; let hoverRing=null;`（RF2 标注）

**`js/ships/11-classes.js`**：makeShip 在 autoEngage 同块（L118 区）加 `macOn:true, mslOn:true, ciwsOn:true,`——默认全开保持现有自动化行为不变

**`js/weapons/57-step-weapons.js`**（三处小改）：
- S16 L32 进入条件加 `!x.ciwsOn||`——关拦截连冷却都不走
- S17 L64 `roeOK` 前置 `s.macOn&&`
- S15 后新增导弹自动齐射段（S15b）：`autoEngage && mslOn && 锁定活目标 && lit≥2 && 距离<35万 && 就绪单元≥ceil(cells/2)` → `orderMissileSalvo(s,t,min(2,ready))`。波次节流靠发射单元 60s 装填天然限流，无需定时器；敌方 AI 走自己的 8% 掷骰路径，不受影响（red 的 autoEngage 恒 false）

**`js/weapons/56-step-projectiles.js`**：导弹命中结算的内圈近防炮循环加 `x.ciwsOn===false` 跳过（拦截开关同时断掉外圈发射与内圈炮）

**`js/command/70-input.js`**（两行）：`shipAt` L9 红舰无条件 continue（GM 也不可选敌）；`updateDragSel` L334 条件改蓝方 only

**`js/command/72-context-menu.js`**：`showCtx` 函数体首行加 `if(SIMPLE_UI)return;`——长按定时器照跑但所有菜单（主菜单/敌舰交战/卡片菜单）都弹不出来；短按右键移动路径（L384 moveShips）不经菜单，不受影响

**`js/render/86-log.js`**：log() 末尾加 `if(typeof pushEvt==='function')pushEvt(msg,cls);`（typeof 守卫保持 88 可选）

**`js/render/83-hud.js`**：新增自包含 `drawHoverRings()`（~20 行，不复用 drawRanges 内嵌的 ringLabel——arc+文字自画）：hoverRing 存在时给每艘选中蓝舰画对应圈：主炮 15 万 / 导弹 35 万 / 拦截 outer+inner 双圈（半径×cam.zoom，颜色用 --acc 系）

## 不动的东西

所有模拟逻辑（sensors/weapons 引导/伤害/物理/编队）、任务/编辑器/回放/靶场/设置的全部函数与绑定（DOM 在、CSS 藏，随时可复活）、键位系统（空格暂停/倍速照常）、拖拽平移缩放框选、Shift+右键路径点。
