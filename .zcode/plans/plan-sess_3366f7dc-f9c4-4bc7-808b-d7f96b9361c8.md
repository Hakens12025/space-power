# DLSS 启动器项目（写作+下载；仍不运行任何脚本）

在 `D:\BaiduNetdiskDownload\Skyrim Anniversary Edition\DLSS_Launcher\` 建立独立完整项目。不改动游戏目录现有文件（只读复制其中可复用的 3 类文件进套件），不运行脚本。

## 一、项目结构与 bat 规格（同上版）

```
DLSS_Launcher\
├── DLSS_Launcher.bat   ← 主启动器：菜单 1/3/C/R/0，换入→SKSE启动→等游戏退出→自动还原
├── Restore.bat         ← 独立手动还原
├── README.md / docs\使用文档.md / docs\电脑现状与设计背景.md / docs\自查报告.md
└── kits\Route1\root\ 、 kits\Route3\root\ + data\
```
核心机制：`state\active` 标记 + `added.log`（新增清单）+ `manifest.log`（被移走原件清单）双清单对称还原；崩溃后下次启动自动恢复现场；删除只碰登记过的路径；HAGS 检查；全程日志。

## 二、下载内容

**路线①套件 → kits\Route1\root\：**
1. ReShade 最新稳定版（6.8.x，带完整 add-on 支持）dll — reshade.me
2. `renodx-dlss5.addon64`、`DLSS5_Feed.fx`、`dlss5-feed`（v0.7.0+）— 优先 Nexus（190077 Skyrim 专用包 / 2224 通用包）、r/nvidia 汇总帖里的直链；只在此二者 Discord 有的文件会明确列出让你登录领取
3. 40 系 CUDA 补丁版运行库（若公开渠道有）
4. 从游戏根目录**复制**（不动原件）：58MB `nvngx_dlss.dll`、非零的 `sl.*.dll`/`nvngx_dlssg.dll`、你调好的 `reshade.ini`

**路线③套件 → kits\Route3\：**
- Nexus 190062「Open Shaders with DLSS5」包 — 需要 Nexus 账号，我用浏览器下载时若要登录会请你操作
- 下载后核对它的游戏版本要求，对照你的 1.5.97 运行时写进文档（大概率仅支持 1.6.x，标注风险，不阻止你试）

Nexus/Discord 若需人工登录，我会停下来把步骤列给你，拿到文件后继续。
