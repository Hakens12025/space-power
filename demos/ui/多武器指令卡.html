多武器指令卡 · 演示(格内分行)

四格位置不变,一类里几种武器就分几行。点绿条 = 选这一发 / 这一组(泛白呼吸),再点取消;点行首名字 = 这一行就绪的全选;点格子空白处或 T / R = 这一类就绪的全选;选好了点地图上的红色目标或空地发射(右键 / Esc 取消)。

右上角大勾 = 这一类的自动开火总开关,行尾小勾 = 这一种的分开关:总开关关着这一类全不自动打(小勾变淡、照记)。特殊格点一行 = 放一个(再点方向)。悬停一行只亮那一种的圈。

几十艘时(点「10 艘护卫」「30 艘」):一行放不下就收成一整条 —— 绿 = 就绪、蓝 = 在装(越深越快好),右边「+8·40s」= 40 秒后再好 8 个。点一下 +1、右键 −1、滚轮加减、在条上拖 = 拉到哪选多少。谁来打由系统挑:轴炮先挑船头对着目标的,其余挑离目标最近的;鼠标停在目标上,地图上描白的就是会开火的船。
