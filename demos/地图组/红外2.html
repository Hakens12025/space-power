点我方船选中(环跟着换)· Shift+点 = 多选加 / 减(多选时各艘画自己的环、每个目标只在一个环上 + 左边仪表 + 地图上画交集)· 拖船(上帝视角下敌舰 / 石头也能拖)· 拖空白处平移 · 滚轮缩放 · 光标放在环上看那个方位的读数

厚度轴(左下切换):温度 / A 重排(压掉中间空的温度段)/ B 连续光谱(厚度 = 波长,每份热按黑体谱铺开)/ C 厚度 = 信噪比、颜色 = 温度 / D 厚度 = 时间(内沿此刻,往外 60 游戏秒前)、颜色 = 温度;画格:现状 = 引擎的格子,加密 = 2 px
