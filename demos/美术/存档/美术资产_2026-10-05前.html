地图语境

五艘船轮着做:主推加速 → 熄火滑行 → 侧推 → 反推刹车 → 小推力巡航;几组导弹前一段喷火、后一段滑行(滑行时没有尾焰);青色 = 拦截弹组;左上是恒星,行星的亮面朝它。第二批:上方一条碎石带 + 两颗小行星,左下一处残骸,两个浮标(右边那个开着照射);蓝红两艘在对射主炮,命中处有爆点,隔一阵在右上方放一次击沉。

尾焰特写

四层焰瓣(外焰 → 中焰 → 内焰 → 白芯)+ 喷口亮斑,叠加混合、长度按墙钟轻微抖动;舰长 ≥ 40 px 时主推多出几道淡淡的马赫环;< 16 px 时几个喷口并成一道。主推从(占位)船体每个喷口的位置喷,反推在船头两侧斜向前(橙),侧推是一侧前后两个短喷(黄白)。

导弹 / 诱饵 / 伏击雷特写

一枚 = 尖头 + 弹身 + 尾鳍,阵营色环带,斜面按固定光向明暗,暗描边;一组画 1 / 3 / 5 枚(3 枚以上画 3、6 枚以上画 5)、楔形队形;喷火时每枚一道小尾焰,滑行时没有(看不出在不在喷 = 引擎现在的问题)。拦截弹更细、比导弹小一号、青色。诱饵 = 脉动的假热源;伏击雷 = 六角壳体 + 三根天线 + 闪烁指示灯。

行星特写

地表按种子生成,七种:岩质(月海 + 陨坑)、冰质(冰裂纹 + 极冠)、荒漠(沙丘纹 + 台地 + 峡谷)、熔岩(暗色地壳 + 发光裂缝,夜面也看得见)、类地(海洋 + 大陆 + 极冠 + 云)、冰巨星(淡青带纹 + 暗斑)、气态(带纹 + 风暴眼 + 正对镜头的环,背光那侧有行星的影子),色调分几档、像平涂;明暗与大气边缘光单独一张、每帧按恒星方向转过去贴,不重画。半径 < 3 px 退回引擎现在的两色圆点。

主炮弹 / 命中 / 击沉

主炮弹 = 白芯 + 阵营色拖尾 + 亮弹头(原来 4 px 白方块)。主炮命中 = 蓝白闪 + 火花;导弹命中 = 闪光 + 火球 + 火花 + 烟;击沉 = 大闪光 + 冲击波环 + 火球膨胀 + 十块残片(按光向两色、朝光的边亮)飞散减速 + 三次连环小爆炸 + 余烬 + 烟,约 3 秒。全是预渲染贴图,叠加混合。

碎石 / 小行星 / 残骸 / 浮标

碎石 = 随机多边形切成小面,每个面按坡向 + 朝上、对着固定光向求明暗(低多边形的样子),大的加陨坑(坑底暗、背光那侧的坑壁亮);按种子、大小、光向缓存。残骸 = 船体沿锯齿断口裂成两截错开,焦痕,断口一排闪烁的余烬,周围几片碎片。浮标 = 中心舱(八个斜面)+ 两片太阳能板 + 天线 + 阵营色指示灯,开照射时一圈圈脉冲环。
