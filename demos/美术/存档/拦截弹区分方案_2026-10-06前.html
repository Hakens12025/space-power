为什么现在分不清

战术落点上最小的船(护卫 T1)长 7.45 px。导弹单枚 = 0.55 倍 = 4.1 px,拦截弹单枚再短一成五 = 3.5 px,成组每枚只有 2.7 / 2.3 px —— 全都低于 5 px 的门槛,所以引擎里两种弹在战术层都画成一道阵营色短划 + 一团阵营色尾焰,只差「拦截弹短一成五、线宽 0.8 对 1、颜色调亮 0.35」。这三样都是连续的小差别,单独看一枚时读不出来。
另外两条边界:主炮弹在战术层是约 20 px 的亮白拖尾(所以拦截弹不能做成曳光长线,会和主炮弹混);阵营照旧走颜色(skill 第 10 节),所以方案只动形状 / 纹理 / 明度 / 闪烁,导弹本身不改。
C 方案靠闪烁,截图看不出,要看动的。

三个方案

方案拦截弹画成区分靠的通道记号好处风险
A 光点群一组画成一小团闪烁的光点(1 / 3 / 5 个,白芯 + 阵营色光晕),各带一丝很短的阵营色尾纹理粒度 + 数量(Bertin 的纹理粒度;subitizing)5 个单像素点排成骰子五点(单枚也一样)「一团碎点」对「一道实线」,成组时最好认;像一群小型杀伤器单枚时只剩一个光点,和 B 差不多;闪烁要是太跳会抢眼
B 白芯亮珠圆珠:白芯 + 阵营色外圈 + 光晕,尾焰缩成一小团;成组排成一字横队闭合 / 长宽比(圆 vs 长条)+ 明度(白芯)白点 + 紧贴的阵营色圈单枚也成立(圆点对短划);白芯在去色后依然最亮2 px 的珠子白芯和外圈会糊成一个浅色点;记号和诱饵(紫点 + 圈)同族,要靠中心颜色分
C 闪烁信标形状照现在(阵营色短划 / 楔形),每枚机头加一盏白色频闪灯:每 0.45 秒亮 0.12 秒,各组相位错开时间通道(闪烁;前注意特征里最抢眼的一类)现在的记号 + 同步闪的白心和尺寸无关,1 px 也成立;导弹那套画法完全不动静止截图里看不出;一屏几十组拦截弹一起闪会很吵、抢注意力
D 阵营色 + 青环(10-06 用户提;同日:一个环就行)弹体满阵营色、长度照现在(导弹的 0.85 倍);中段一道青色环,比弹身宽、上下各伸出一点;尾焰照现在(阵营色)。战术层画短划时,环画成横穿短划中段的青色小竖条形状细节(短划上的横条)+ 色相点缀;阵营仍由弹体与尾焰的颜色定现在的记号外加一圈青色敌我和现在一样清楚;放大后就是「阵营色弹体 + 一道青环」战术层的环只是 1~2 px 的小竖条,蓝方的青环和蓝色弹体色相接近
