独立演示页(不加载引擎)。默认比例尺 = 引擎战术落点:左下比例尺 100 px = 2.5 万 km(每像素 250 km)。舰标大小照引擎:系数 = 0.55 x (缩放 / 战术落点)^0.4,钳在 0.45 ~ 1.9,舰船再 x 0.6; 原始系数低于 0.45(比例尺约 4.1 万起)船换箭头 / 菱形,弹同时换简易记号 —— 代表显示;以上是真显示。
「美术整体缩放」= 一个总系数:船、尾焰、导弹 / 拦截弹、主炮弹、雷、诱饵、命中 / 击沉、近防火花、护盾受击、残骸全部一起乘(默认 1.25,用户 10-05:真图放大一点点;想让船再大一点,其他跟着一起大);武器对船的倍数不变。切换点和代表显示的记号不跟着变,行星照实际大小。
特效随缩放(用户 10-05):命中 / 击沉、近防火花、护盾受击的大小 = 战术落点上的大小 x 船的(不钳)系数开平方 —— 船缩到 0.5,特效缩到 0.71;拉过切换点以后船换了记号,特效照样慢慢变。
舰船 = 引擎现在的轮廓(护卫用原驱逐轮廓、驱逐用细长楔形、巡洋、航母;没认出的是通用灰轮廓)。武器尺寸以最小的船(护卫 T1)的舰长为基准:物品本体(成组导弹算整组外框)不超过 0.8 倍;尾焰、拖影、爆炸、光晕是效果,不算。 滚轮缩放、拖动平移;上面「灰度」「模糊」是检验:去色后还分得清敌我、糊一点还认得出。

和引擎现在的差别

  • 美术整体缩放:所有真显示资产在引擎尺寸上再乘这一个数(默认 1.25,等于把引擎的 SHIP_K 0.6 调到 0.75);切换点、代表显示的记号不变,武器对船的倍数不变。
  • 特效随缩放:引擎里命中 / 击沉跟船同一个系数、拉过切换点就停住不变;近防火花是固定像素、完全不变;护盾受击半径跟船、线宽固定。这里三样都改成「战术落点的大小 x 船的不钳系数开平方」,拉远到战区层约 0.48 倍、拉到最近约 1.8 倍。
  • 行星:照抄 81-art 的冰巨星画法(地表噪声分档色带 + 暗斑、4 阶明暗朝恒星、大气边缘光),只做了靶场那一颗,照实际大小。
  • 舰船:轮廓、尺寸、Tier 明暗都照引擎;舰体从纯色平涂改成阵营色材质 —— 按固定左上光朝光亮、背光暗,外加约 0.8 px 暗描边;舰长 ≥ 12 px 时朝光的边亮一档;炮塔等构件照旧压暗。阵营色仍占整个剪影,6 px 时也分得清敌我。
  • 导弹:弹身从灰色 + 约 1 px 阵营色环带改成整枚阵营色;尾焰从两方同为橙色改成带阵营色(蓝方蓝白、红方橙红)。单枚 0.55 倍最小舰长,成组每枚 0.36 倍,5 枚一组整组外框 0.79 倍。去掉了引擎里 4.5~5 px 的像素下限,和船同一个系数缩放,所以任何缩放下都比船小;弹长 < 5 px 时画成一道阵营色短划。
  • 拦截弹:同形更细、短一成五,阵营色调亮;尾焰也调亮。
  • 雷:六角壳体改成阵营色暗调 + 阵营色描边 + 阵营色指示灯;连天线 0.67 倍。
  • 诱饵:罐体改成阵营色;紫色的假热源光晕照旧(效果,不算物品)。
  • 照抄引擎没改的:舰船尾焰(主推蓝、反推橙、侧推黄)、主炮弹(拖影本来就分阵营色;弹头约 0.19 倍)、命中 / 击沉、残骸(不分敌我)、代表显示的所有记号。
