UNSC 舰船图标 · 图标质量 + 肖像质量

独立演示页(不加载引擎)。四个舰种各按一种 UNSC 舰级的外形语言画:驱逐 = 巴黎级护卫舰的刀形舰首 + 后掠短翼;巡洋 = 马拉松级的锤头舰首 + 收腰宽肩;战列 = 哈尔西翁级(秋风号)的大锤头 + 细长舰颈 + 厚重舰尾;航母 = 纪元级 / 无尽号的分叉舰首 + 宽平舰体 + 侧舷机库。
同一套几何两种画法:图标质量 = 地图上跟着航向转的小图标(光从固定方向来,斜面明暗随航向变;按像素大小逐级加细节);肖像质量 = 放大的精细渲染(面板线、导弹舱、近防炮、机库、舷号、引擎喷口),渲染一次缓存,给以后选中后的下方菜单用。
