# tools/replay —— 基准对局录像与回放(2026-10-06)

## 文件
- `run.mjs` 录一局:`node tools/replay/run.mjs 种子 打法 上限游戏秒`(打法 radar / silent / turtle / rush,蓝方是基准脚本,红方走 enemyAI)。1 个无头 Chrome、自己降成低优先级(Chrome 继承),分块取回,写 `录像/<种子>-<打法>-<时间>.json`(录像目录在 .gitignore 里)。
- `rec.js` 注进无头页的录制器:`recMatch({seed,pol,cap,frame})`,录像 `v:2`。每 `frame`(2)游戏秒一帧:舰船 + 民船的真实状态、在飞的导弹 / 炮弹(带「哪方看得见」位)、浮标 / 诱饵、卫星 / 彗星 / 电离云偏移 / 据点归属、每一方的接触(航迹状态 + 它以为在哪 + 认没认出)、炮弹来路、指挥层的路径与当前线索;每 30 游戏秒一张搜索图(字节)。事件:开火(新出现的弹)、命中 / 击沉(包一层 applyDamage)、航迹状态变化。`meta.ll` = 这一局光速延迟开没开。
- `回放.html` 不加载引擎,打开录像 json:全知 / 红方视角 / 蓝方视角,时间轴(开火、击沉、首次定位的刻度)、事件列表点了跳过去、空格播放、左右键逐帧(Shift 一分钟)。

## v2 格式(光速延迟,sensors/26)
- 帧 `p`:[类型, 阵营, x, y, 颗数, 位, 红眼里 x, y, 蓝眼里 x, y];位 1 红看得见 / 2 蓝看得见 / 4 真弹已消失、只剩眼里的余像(全知不画);弹影只记看得见的那一方,光还没到为 null。
- 帧 `v[方].k`:[名册号, 航迹状态, x, y, 认出, 情报龄](游戏秒,`contactAge`,从没定位过为 null);`v[方].st` 这一方看到的据点归属(`staHolderSeen`)。
- 事件:`hit` = [t, 'hit', 挨打, 射手, 武器, 船体, 护盾, 红看见, 蓝看见];`kill` = [t, 'kill', 沉, 射手, 武器, 红看见, 蓝看见](null = 一直没看见;自己的东西当场知道);`fire` 的 t 取光锥层开火表(对上这批弹出生那一步),末两格 = 红 / 蓝看见开火闪光的时刻(开火处、光到这一方最近那只眼,26 `llSee` 不设可见光圈门;射手那一方 = t);事件按 t 排序,时刻存到 0.01 游戏秒。

## 规矩
- 坐标存成 100 km 一格的整数;回放页同一单位。
- 录制只读不改:除了包 applyDamage(录完还原),不碰模拟。事件不靠 `log()`(SL1 已删),从现成的口子取。光速延迟的格只读 sensors/21 的门面(`projImg` / `projAll` / `contactAge` / `staHolderSeen`)与 26 的表(`LL_H` 的开火表、`llDeadSeeT`);命中看见时刻用 26 `llSee` 填一个草稿事件,不进 `LL.ev`。
- 回放页红 / 蓝视角画这一方眼里的弹影、命中 / 击沉 / 对方开火(看见开火闪光)的刻度与列表按这一方看见的时刻(列表末尾写比实际晚几秒)、据点画看到的归属;全知与「叠真实位置」画真值。改录像格式要升 `v`,回放页按缺格回落真值、旧录像照样能开。
- 一次只开 1 个浏览器(用户 10-06:开 8 个并行就「卡的飞起」)。
- 视角里只有方位的接触不画方位线 / 扇形(游戏规矩),列在舰船栏。
