## 规矩
- 不分阵营:三层都收 side;探针里拿它开蓝方和旧红方对打(scratchpad 的 t_vsold4.js,4 对 4,旧版在 git e7accaa)。
- 只读这一方知道的:航迹表(`contactFix` / `contactPos` / `trkPid` / `trkFoe`)、信念层、ESM、`SHELL_TR`、地图事实、自己的船。不读对方真值;未定位接触的 `cov.x / cov.y` 与量测记录的真距离 `ch[2]` 不读(角误差用 `ch[1]/ch[2]` 的比);舰种只经 `contactIdn` 认出后才查。
- 防作弊探针:把这一方航迹表里 'none' 的对方船随便挪,`belStep` 结果必须逐位不变(t_bel.js);信念层每加一块状态(如 `B.flash`),探针两遍之间都要一起还原。
- 没有位置先验(用户 10-05:「没有位置先验,以后都是随机的」):不许用「游玩区按两军中点摆」之类反推对方开局。搜索偏向据点与游玩区中部(双方都知道的交汇点,`FOCAL_K`),不读对方位置;搜索时不扫雷达(旧 AI 被人利用的正是没事就扫)。
- 树的条件用有物理意义的量比,不用「跟够多少秒」:线索的不确定圈 `aicClueU` vs 照射量程(开雷达)/ 可见光圈(放浮标)/ 导弹射程(打一轮);确认是战舰 = 认出 / 炮弹来路 / 雷达与炮弹来路落在同一处(`aicWarship`,用户自述的关联法)。
- 火力纪律(用户 10-05:「老远就能看到红方在乱射导弹火炮」;10-06:「感觉那个地方是船,就可以开火,但是就不要做成之前的那种全星图随机乱抽奖」):打击时主炮只打定位了、认出是船的,把握过门(隐蔽 `GUN_P_HID` / 已暴露 `GUN_P_EXP`),开完横移。没有定位目标时的开火只看一个量:一轮导弹(飞到点再直飞、导引头 `GUIDE_SEEK` 内自己找)扫过的带子里有对方战舰的概率(线索沿线的分布 x 搜索图,乘「是战舰」的先验:认出 / 炮弹来路 = 1,否则 = 没定位的对方战舰 /(它们 + 没认出的民船),民船数读 world/14 的规则表),过 `FIRE_P` 才打;一条线索一次、一次一艘(已暴露的优先),主炮只在圈小于可见光圈且确认是战舰时加一炮;没认出的定位接触先认人不打。还手:有冲着我方来的炮弹 / 导弹 ⇒ 被打的那艘(和本来就暴露的)沿来路往回打一轮、扫一拍,每个导弹装填周期最多一次。
- 红外管制(`aicQuiet`,条令 `IR_QUIET`,稳健关、伏击开):没在打、没暴露时站位挪不到一个可见光圈不改航向、到点停下、按段长选档;「暴露」不算自己的点火(算了就会一点火就放开、接着点火)。
- 队形:跑完树再收(`aicSupport`),各舰站位离全队中心不超过 (导弹射程 - 可见光圈) / 2 x `SUPPORT_K` —— 任意两艘相距不超过 射程 - 可见光圈,谁看到 / 被打的对手全队都打得到(10-06 回放:散开时被各个击破)。别在分支里各自派远。
- 一次性动作(扫描、诱饵、浮标、齐射、开火)执行层执行完就清,60 隔 `DEC_S` 才重排 plan。
- 规避照旧不做(2026-09-28):炮弹进可见光圈到命中太快、躲不开,点火还更亮;来袭导弹只有近防在管(蛇形是躲远程炮,不是躲近的)。
- 改条令先改 `AIC_DOC` 的表(稳健值 + 可调范围 + 含义),别在代码里写新数。对比用 scratchpad 的基准脚本,默认只开 1 个无头浏览器顺序跑、低优先级(用户 10-06:开 8 个并行就「卡的飞起」);查输局用 tools/replay 录像回放,结果要在没参与的种子上复测才算数。
