## BOT1 红方条令层(2026-09-22 用户拍板)

用户:「红方 bot 系统都需要重做,**现在的 bot 感觉做的很粗糙**,需要完整重做,做的更聪明」。

### 改前是什么形态

一个**单层脚本**(`enemyAI`,103 行):一个舰队级目标点 → 三艘船沿前进方向横排 → 每艘各自锁**自己最近的**、
各自**每 tick 掷 8% 的骰子**发导弹、进了主炮 50% 把握距离就**停车找窗口**。
AI1(只读自己的接触图)那一层是好的,留着;粗糙的是它上面本该有而没有的东西 —— 没有指挥层,所以
「集火」「不冲进对方射程」「挨打就撤」「谁当灯」这些**决定根本没有地方可写**。

### 先给业内叫法(不然这轮做的东西没有名字)

| 我们做的 | 标准形态叫什么 | 出处 |
|---|---|---|
| 指挥层 + 执行层 | **分层 AI**(hierarchical AI):指挥 / 班组层 + 个体行为层 | Halo 的行为树(Isla, GDC'05)、Killzone 2 的 HTN 规划(Straatman)、CoH 班组 AI |
| 全队集火同一个 | **WTA**(weapon-target assignment,武器-目标分配) | 运筹学标准问题;游戏侧是 Dave Mark 的 IAUS 效用系统 |
| 六个态的条令 | **doctrine / ROE** | 海战沙盘 Command: Modern Operations 有专门的 doctrine 对象 |
| (没做) | **影响图 / 威胁场**(influence map) | Tozour, AI Game Programming Wisdom |

三艘船的局面用不上一张影响图,**这一块是明知道而没做的**,不是忘了。真要做是下一轮的事。

### 分层

- `js/bots/60-doctrine.js` = **指挥层**。纯决策:读接触图与自己的状态,写 `RDOC`(含每艘舰的 `plan`)。**一艘船的字段都不碰。**
  AI1 的信念层(`AIR` / `aiRedBelief` / `aiSearchWp` / `aiObjective`)整体从 61 搬到这里,逻辑一行未改 —— 它回答的是"该往哪走",那是决策。
- `js/bots/61-enemy.js` = **执行层**(103 → 47 行)。照 `RDOC.plan` 去走、去亮灯、去锁、去开火、去规避。**改行为去改 60,不要在这里加 if。**

### 六个态

```
ambush ──接触/时限──► search ──接触──► shadow ──定位──► strike ──打够一段且以多打少 / 弹尽──► press
                                                          └──结构 < 45% 且还有弹──► withdraw ──弹尽──► press
```

| 态 | 什么时候 | 干什么 |
|---|---|---|
| `ambush` | 开局、还没有任何接触 | **全静默、原地不动**,等你自己亮灯或撞进来。**有时限**(`AMBUSH_S` 420 秒,用户拍板)—— 憋够了转 search,不许变成双方都蹲着的空局 |
| `search` | 没接触 | 走五角星航点(AI1),**一盏灯**扫。不扫的话静默熄火的玩家永远不会被找到 |
| `shadow` | 有接触、定不出位置 | 沿方位线推进 + **横向拉开 `SPREAD`** 交叉定位,保持静默;憋 `SHADOW_S` 还定不出 ⇒ 亮一次灯抢定位 |
| `strike` | 有定位 | 绕着接触的**估计位置**走轨道,半径 = min(对方主炮 30% 把握距离, 自己导弹动力射程 x0.95);**一直在动** |
| `press` | 打够 `PRESS_AFTER_S` 且以多打少,或**弹打光了** | 进到主炮过半把握距离的八成,**清命令停车** |
| `withdraw` | 舰队平均结构 < `HP_WD` 且还有弹 | 退到对方主炮 30% 把握的距离(64 万),继续用导弹(滑行段)打 |

**转移条件里只许出现红方自己知道的量** —— 它不知道蓝舰的血量、弹药、编成,所以那些一个都没有。

### 三条这一轮量出来 / 想明白的事

1. ⚠ **WR1 之后没有「站在对方武器包线外打」这回事。** 主炮过半把握 36.6 万、导弹动力射程 37.5 万,两个带几乎重合;
   真按"对方够不太着我"站(30% 把握 = 64 万),自己的导弹就只能滑行过去。
   **条令的杠杆因此不是距离,是【机动还是停车】** —— 主炮要机头对准才打得响,而战斗转向只在【空闲】(没有命令)时抢机头(`physics/31` 的 `idle`)。
   于是:交战态一直沿轨道机动 ⇒ 自己开不出主炮、也难被主炮打中(WR1 的弹丸瞄的是**发射那一刻**的预测点,飞 12 秒,目标横move 9600 km 对 2000 km 的判定半径);
   只有压上态才清命令停车。**「谁停下来谁开得出炮」从 WR1 那一轮的一条实测缺陷,变成了一个明写的决定。**
2. ⚠ **压上必须是个【闩】。** 第一版把它写成每拍重算的条件,而"打够一段"的计时器 `strikeT` 在离开 strike 那一拍归零 ——
   于是压上那一拍归零、下一拍门槛又不满足,两个态**逐拍互翻**,行为和读数都在抖。现在 `RDOC.press` 是闩:够条件扭上,撤退时扭下来。
   **凡是"积累够了才允许"的转移,都要检查它的计时器会不会被新态清掉。**
3. ⚠ **ID3 在这里第一次有了回报。** 「对方那一型主炮打我打得多准」与「哪个目标更值钱」都先问 `contactIdn`:
   认出来了才查它的舰种(`resolveLoadout(cls,tier).macSigma` / `shipValue`),**没认出就按最危险的一型算、价值记 1**,绝不偷看 `b.cls`。
   认出航母 ⇒ 它根本没主炮 ⇒ 可以贴上去。这条同时是 AI1「只读自己的接触图」那条纪律的延伸。

### 判据与变异

`FLOW87_BOT` 七条,每条自带反向对照:① 不冲进主炮带 + 一直在动(反向:凑齐压上条件 ⇒ 冲进去且停车)
② 集火同一个、目标沉了全队同拍改口 ③ 交战态恰好一艘照射 + `LAMP_S` 后换人 ④ 齐射是决定不是骰子
(**直接记 `orderMissileSalvo` 的调用**,不数弹丸 —— 发射单元有装填延迟,数弹丸数的是另一件事;反向:单元全不就绪 ⇒ 一次都不下令)
⑤ 挨打就撤、弹尽转拼命 ⑥ 埋伏有时限 ⑦ 不偷看。

跟着改的旧判据:`FLOW71_AIFOG ⑤`(横向站位)改成在**尾随态**量 —— 那才是这条站位规则服务的场合;
有了定位之后红方进交战态、改走轨道(基线更大),那一半归 `FLOW87_BOT`。
顺手修了 `FLOW71 ⑤` 一个**陈读数**:判定用的是当场算的值,读数却要等 ⑥ 跑完才拼字符串,那时 `AIR.goal` 已被改过,显示成 `false` 而判定是 `true`。

| M7 交战态也停车找窗口 | ✗ 抓到 |

⚠ **判据自己的两个洞,都是变异验证逼出来的 —— 两条都值得记住:**

1. **判据的循环长度不许由它要测的那个常数决定。** ⑥ 原来写 `run(ceil(AMBUSH_S/2)+10, 2)`:
   把 `AMBUSH_S` 变异成 `1e9` 之后,这一行变成**五亿步**,整个探针挂死二十分钟(我先把它误判成"M1 让探针死循环")。
   现在步数固定 400、**步长**按时限现算,并且补了一条表级不变量 `AMBUSH_S <= 900`(埋伏时限必须是一局里等得到的数)。
   —— 只判行为、不判那个数本身,改多大都能"跨过去"。
2. **数值上恰好相同的两条路,判据分不出来。** ⑦ 原来比的是「没认出时的 σ」和「最危险的那一型的 σ」,
   而四个舰种今天的 `macSigma` **完全相同**(都是 0.0081),于是"直接偷看 `b.cls`"这个变异算出来的数一模一样,判据全绿。
   现在改成**拿航母当目标**:航母没有主炮,认出来 σ=0、没认出必须按最危险的一型算 σ>0 —— 两条路的答案天生不同,偷看当场露馅。

### 整局模拟(3 个种子;替身玩家 = 全照射 + 开火控 + 编队朝战场中心)

第一版跑完读出三个毛病,都不是条令写错,是**没在真局面里量过**:

| 毛病 | 实测 | 改法 |
|---|---|---|
| 红方首发导弹出在 **50 万公里**(动力射程才 37.5 万) | 弹药扔进滑行段 | 齐射窗口在 60 里用的是**队心**到接触的距离,而三艘舰散在一段弧上;执行层(61)补一道**按本舰**量的 `d <= mslReach*1.05` |
| 红方在尾随态蹲了 **35~43 分钟** | 整局只抢过一次定位 | 尾随态的照射窗口原来是**一次性**的(`paintT` 只增不清);改成**黑 90 秒 / 亮 25 秒**循环 |
| 红方齐射 23 波 vs 蓝方 132 波 | 火力只有蓝方的五分之一 | 蓝方那边(weapons/57)是"每舰就绪单元过半就打",红方一道舰队级门把它压死了;`SALVO_GAP` 45 → 25 |

改完之后(同样三个种子):首发 **37~38 万**(正是条令半径)、尾随 26~32 分钟、交战态 17~19 分钟、
**交战态 100% 的取样点都在动**(平均航速 756 km/s,巡航 800)、最近逼到 26 万。三局蓝方全胜(43~51 分钟)。

⚠ **还剩一条没解决的不对称**:蓝方齐射 84~126 次、红方 18~19 次。
红方是**舰队级**一道门(25 秒一波、每舰 2 组),蓝方是**每舰各打各的**(就绪过半就打,约 30 秒一轮 x 3 艘)。
这不是 bug,是两套节奏 —— 要不要把蓝方的自动齐射也收成舰队级(或者把红方的门放开),是个平衡问题,**归用户拍板**。
另一条读数:交战态的半径中位数 54 万 > 条令的 35.6 万 —— 那不是站不住位,是**大半个交战态都在路上**
(红方一拿到定位就进交战态,那时往往还在 130 万开外,全速接近要十几分钟)。
