# js/bots —— 红方 AI(分层:指挥层 + 执行层)

## 文件
- `60-doctrine.js` 指挥层,纯决策:读接触图与自己的状态,写 `RDOC`(含每艘舰的 `plan`)与信念层 `AIR`(`aiRedBelief` / `aiSearchWp` / `aiObjective`)。不碰任何舰船字段。
- `61-enemy.js` 执行层:照 `RDOC.plan` 去走、亮灯、锁、开火、规避。改行为去改 60,不要在 61 里加 if。命令点同蓝方一样推出天体 / 恒星圈、穿过就绕(world/12 `envBodyOut` / `envDetour`)。

## 条令的六个态
`ambush`(开局静默不动,`AMBUSH_S` 时限)→ `search`(五角星航点,一盏灯扫)→ `shadow`(沿方位线推进、横向拉开 `SPREAD` 交叉定位)→ `strike`(绕估计位置走轨道,一直在动)→ `press`(打够 `PRESS_AFTER_S` 且以多打少、或弹尽:进主炮带停车)/ `withdraw`(平均结构 < `HP_WD` 且有弹:退到主炮 30% 把握距离外用导弹打)。

## 规矩
- 信念与接触计数跳过已确认不是船的(`trkFoe`),否则队心被认出的石头 / 民船拉进碎石带、整局不动(2026-09-28 实测)。
- 只读红方自己知道的:目标点只来自接触图(`fix` 估计位置 / `brg` 方位线推进 `LEAD` / `mem` 记忆 `MEM_S` / `search`),不读蓝舰真值,不读未定位接触的 `cov.x / cov.y`(它仍等于真值)。
- 转移条件里只许出现红方知道的量(不知道蓝舰血量、弹药、编成)。舰种只经 `contactIdn` 认出后才查;没认出按最危险的一型算、价值记 1,不许读 `b.cls`。
- 条令的杠杆是"机动还是停车":主炮要机头对准才打得响,战斗转向只在空闲时抢机头。交战态一直机动,只有 `press` 清命令停车。
- `RDOC.press` 是闩(够条件扭上、撤退扭下);"积累够了才允许"的转移要查计时器会不会被新态清零。
- 交战 / 压上态恰好一艘一直照射,`LAMP_S` 后换人;搜索 / 尾随态改成当灯那艘每 `PULSE_S` 秒扫一拍(`plan.ping` → `pingReq`),扫完立刻换人(2026-09-27)。
- 第一次握住接触(离开埋伏)时,两艘不当灯的船各往舰队中心两侧 `LURE_OFF` 放一个诱饵(`plan.lure` → world/14 的 `launchLure`),每舰一个。
- 齐射:间隔是舰队级(`SALVO_GAP`,同拍一起打),弹药就绪每舰自己答;执行层按本舰距离再判 `d <= mslReach*1.05`。
