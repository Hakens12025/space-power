# js/scenario + js/bots + core/06 —— 对局(垂直切片)备忘

这一份是**踩坑记录**,不是文档。四段是同一轮做的(2026-09-21),标记分别是 `AI1` / `FX1` / `MT1` / `TC1`。

用户问「怎么做才能让这个游戏好玩」。标准答案是 Sid Meier 那句(游戏是一系列有趣的决定)+ MDA 框架(机制 / 动态 / 体验):
当时机制很厚(误差椭圆、三通道、量程律),**动态是空的** —— 没有第二个按同样规则行动的对手,所以体验无从谈起。
该做的东西叫**垂直切片**(vertical slice):一局完整、可输、可重玩的最小对局。题材范本是潜艇模拟的 TMA(Cold Waters)与 Nebulous: Fleet Command。
用户拍板:四条都做,默认仍是靶场,给一个对局入口。

## AI1 红方 AI 只读自己的接触图(`bots/61-enemy`,连带 `bots/60-tasks`)

改前 `enemyAI` 取**全部蓝舰真实位置的重心**当目标点,没有识别级接触时目标池还回退到全体蓝舰真值 —— 静默、熄火、分散站位对它全部无效。
现在「该往哪走」只有四个来路(`aiRedBelief`,只写 `AIR`):

| 来路 | 条件 | 去哪 |
|---|---|---|
| `fix` | 有定得出位置的接触(`contactPos(s,'red')` 非空)| 这些**估计位置**的重心 |
| `brg` | 只有热区(`contactState==='heat'`)| 沿方位线推进固定一段 `LEAD`(20 万)。方位是合法情报,距离不是 |
| `mem` | 接触全丢了 | 最后一次的目标点,`MEM_S`(120 s)后放弃 |
| `search` | 什么都没有 | 战场中心(场景的 `objective`),到了再按五角星次序绕 `RING`(40 万)的圈 |

- 三舰沿前进方向的**横向**拉开 `SPREAD`(6 万):纯方位接触要靠基线交叉定位。
- **搜索照射**:到了战场中心还没接触 ⇒ **只有旗舰**开照射,两艘僚舰静默。不加这条,一个静默熄火、一动不动的玩家永远不会被找到(僵局);
  加了之后轮到玩家做题 —— 你会先听见它。
- 规避只对 `p.visRed` 的来袭主炮触发(原来不看,等于红方对每一发主炮都有预警)。
- ⚠ **刻意不读未定位接触的 `cov.x / cov.y`**:它今天仍等于真值(模型不模拟估计误差,见 `js/sensors/CLAUDE.md`),读了就是从那个已知的口子作弊。
- ⚠ 对局里红方的导弹齐射改用与蓝方自动齐射同一套纪律(过半就绪才打、每波 2 组),门控在 `matchIsOn()` 上;预设场景(回归基线)仍是「就绪单元全发」。

**判定** `FLOW71_AIFOG`,最硬的判法是**不变量**:把蓝舰真实位置挪来挪去,只要红方握着的接触没变,红方的目标点必须**逐位**不变。八个变异全部被抓到。

## FX1 开火暴露(`sensors/20` 常数、`sensors/22` `firePowerOf`、`weapons/52` 置位、`weapons/57` 倒数)

开火这个决定此前**没有代价**。现在主炮 / 导弹发射之后 `FIRE_S`(8)秒里光学亮度多加 `P_FIRE`(3.0,= 主推点火)一档,敌我对称:冷船开火那几秒光学量程 x2。
只算进攻性发射;被火控门静默挡回的不亮;拦截弹 / 诱饵弹(防御)不亮。`FLOW72_FIREFLASH` 含一条端到端(冷船看不见的距离上,一开火下一拍就被看见,熄了又看不见),六个变异全抓到。

事实更正(动手前查到的):「玩家决定开火」大半**早就存在** —— 蓝方 `autoEngage` 默认 `false`,要中键点目标才交战。缺的只是代价。

## MT1 对局(`scenario/97-match`,场景在 `90-envs` 末尾)

- 3 对 3 镜像(CA + 2 DD),双方静默、熄火、静止;红蓝重心恰距 `MATCH.OPEN`(120 万 = 尺度预算里「开局间距 >= 最远雷达发现 114 万」那条单边硬规则)。
- 红方出生方位在 ±60° 内随机(`matchPlaceRed`,掷骰可注入)。**位置固定就没有「找」这回事。**
- 入口是顶栏 `#btnMatch`(进了对局变成「回靶场」);结果卡片 `#matchEnd` 只在对局里弹(`matchTick` 挂在 `frame()` 里)。两者都不属于 RF2 隐藏清单。
- 场景**追加在末尾**(第 7 条):索引 1..6 是回归基线,插中间会全部挪位(变异 t6 钉着)。
- ⚠ 引擎里**没有战场边界**:`CFG.world` 只管星空贴图与开局镜头。所以「战场 200 万」不是一个要改的数。

## TC1 接触降速(`core/06-timecomp`)

移植演示页的 `TC`:握有定得出位置的接触 x6 / 估计位置进导弹射程 x4 / 进主炮射程 x2;只读我方知道的事、热区不触发、变慢立刻、变快等 4 墙钟秒。
比演示页多一条:我方**看得见**的来袭导弹直接进交战档(演示页里没人还手)。**只在对局里生效**(靶场是调试台)。
`FLOW74_TC` + 一条源码级检查(`frame` 里真的调了 `tcStep(dt)` —— 判据量的是算得对不对,接没接上只能从源码看)。
⚠ 第一版的变异 c1(「热区也触发」)是个**空变异**:`contactPos` 对热区本来就返回 null,后面还有一道 `if(!p)continue`,两道保险。换成「交代不出位置就回退真值」才是真的。

## FG1 敌方的意图不上图(`render/82-ship-icons` 的目的地线、`weapons/56` 的 `corridorFrom`)

用户玩了对局之后实报:「我应该不能看到敌方的目标线和目的地线才对」。两处,都是在「有一个会动的对手」之后才显眼的:

- **目的地线**:`drawShip` 尾部的「当前目标连线」不分阵营 —— 红舰被定位之后,它要去哪就实时画在图上。SN6e 只堵了陈旧与失联两档,实况这一档漏了(待办 F5)。
  AI1 之后它更要命:红方的去向 = 它对你位置的**信念**,画出来等于把「敌人以为我在哪」直接告诉玩家。现在只画我方(GM 照旧),口径与 `drawOrders` / `drawLocks` 首行一致。
- **来袭走廊的来源线**:起点原来取发射舰的**真实位置**,哪怕那艘船根本没定位 —— 一轮齐射就把射手坐标白送了。
  现在:射手定得出位置 ⇒ 从**估计位置**画起;否则从我方**第一次看见这组导弹**的地方画起(「从那个方向来的」是合法情报,「谁在哪打的」不是)。

`FLOW76_REDINTENT` 三组(含一条真发导弹过 `stepProjectiles` 的生产路径),五个变异全抓到。
⚠ 还没查的同类:`#xhTip` 敌舰信息卡、`drawLocks` / `drawFcChain` 指向真值(待办 2.11 G 记着)。

## 整局模拟得到的三个事实(比上面四段都值钱)

写了一个替身玩家(全队开火控 + 开照射),无界面跑完整对局,每种策略 6~8 局:

1. **第一轮:0 胜 14 负,红方几乎零损失。** 先怀疑红方齐射火力大(改了,没用),再怀疑红方会躲主炮(对照实验:关掉规避照样 0 胜 6 负)。
   最后数出来的是**开炮次数**:蓝炮每局 1~4 发,红炮 16~19 发。
2. **根因与迷雾、与 AI 都无关。** `physics/31` 的战斗转向只替**空闲**的舰摆炮口,而编队成员不算空闲;要它们归瞄靠 `driftFire`。
   火控序列(中键)每拍续它,**自动索敌(底栏「火控」钮)从来不给** —— 开着火控的编队,主炮只在碰巧对准时才响。
   对照实验:同一套策略,保持开局编队 0 胜 6 负,解散编队 6 胜 0 负。靶场里看不出来(靶不还手)。
   修在 `weapons/57`:自动索敌锁着目标时每拍续 `driftFire`(`FLOW75_AUTOAIM`)。**这是一个只有在「有人还手」时才会暴露的 bug —— 垂直切片的价值就在这儿。**
3. **修完之后:16 胜 0 负。** 「全队开照射 + 开火控」这个无脑策略稳赢,每局只损失 0~2 艘。
   也就是说**今天的胜负手是主炮对射的站桩优势,不是迷雾**:红方冲进射程、停车、再转头瞄准,而等着它的一方炮口早就摆好了。
   亮灯的代价(被听见)在这局里没有咬人 —— 这是下一轮要解决的,见 `todo-plan.md`。它需要真人试玩来定,不是再写一轮机制。

**判据里的教训**:`FLOW6_PULSE` 偶发红(约每十几次一次),与被测代码无关 —— 波形是 |sin|,+260ms 差不多正好半个周期,两个相位会撞成同一个灰阶。撞上了再推 130ms 量一次。
