# js/net —— 联机(开场菜单、大厅、房间、锁步对局)

## 文件
- `98-net.js` 传输层与房间协议:总线 `netBus(name)` → `{post, on, close}` 两种实现 —— Supabase Realtime 广播(`NET_CFG.SB_URL` / `SB_KEY` 填了才用;脚本先读仓库 `js/vendor/supabase-js-2.45.4.umd.js`,读不到再去 CDN,10 秒没拉到就报错 + 重试,不悄悄退回)与同源标签页 `BroadcastChannel`(没填时的本机测试);协议只写一份:大厅 `sp-lobby`(房主定时广播房间、新人先问一声、关房说一声)、房间 `sp-room-<id>`(加入 → 房主答应 / 拒绝、双方心跳、离开、对局数据 `{t:'m'}`)
- `98-lobby.js` 开场菜单与大厅界面 `#spMenu`(样式在 css/app.css 末尾那一节):单人游戏 = 关菜单、照旧是现在的页面;多人游戏 = 大厅(昵称、房间列表、创建 / 加入)→ 房间;对手到了主机定种子发 `{t:'start'}`,双方 `lockBegin`
- `98-lock.js` 锁步:主机按自己的倍速推进,每 100 ms 广播「可推进到第几拍 u」+ 排进去的命令 + 倍速 / 暂停;命令一律排在主机此刻那一拍(加入方的先发给主机 `gc`);加入方只推进到 u、落后就追,心跳 `gk` 报自己到了哪一拍;每 250 拍对一次 `simHash`;航线细化每 10 拍一次(两边同拍);`lockUi` 顶上状态条 `#mpBar`

## 规矩
- Supabase 项目 space-power(东京,ref `vychqfgrwniauccpxtse`)。代码里只放项目地址与 anon 公开密钥(本来就公开);`service_role` / secret 密钥与数据库密码绝不进仓库。Realtime 只用广播频道,不建表。
- 只有在线版(http / https,即 GitHub Pages)出菜单;本地 file:// 照旧直接进靶场,地址加 `?menu=1` 在本地也出。
- 菜单开着时模拟停着(core/01 `running` 默认 false,单人游戏也是空格开始);键盘在 window 捕获阶段拦掉,菜单里的输入框照常打字。
- 名字、房间名都来自网上,写进页面一律 `spmEsc` 转义。
- 版本指纹 `netVer` = 页面上全部脚本 `?v=` 的哈希;不同的不许进同一房间(锁步要两边代码逐字相同)。改了任何 js 都要照常改版本号。
- 锁步成立的三个前提,破了任何一个两边就分叉:① 模拟里的随机数一律 core/00 `simRand` / `gaussRand`(开局 91-init 按对局种子 `simSeed`,种子要在建局之前定);② 玩家的改动一律走 command/68 命令;③ 模拟不读界面状态(选中、鼠标、视角、ME)。查分叉:`LOCK.dbg=[]`、`LOCK.dbgN=前几拍`,lockTick 逐拍记校验和与执行的命令。
- 联机时主机 = 蓝方、加入方 = 红方(模拟里不对调);`ME` / `VIEW` = 自己那一方,配色走 core/01 `palSide`(我方画蓝)。红方 AI 不跑,红方开局的开火 / 雷达开关照同舰种蓝方、舰名去「敌·」续编号、开局编成一队。
- 编队槽位按阵营分开:加入方的 1~4 号是编队键 5~8(formation/42 `fmKey` / `fmSlot`),界面只列我方的(`fmAllMine`)。编队编辑页(render/89-fmpage)还在直接改编队参数,联机时挡住。
- 倍速 / 暂停共享:加入方按了发给主机(`lockCtl`),主机改了随广播走。主机领先加入方不超过 300 拍。
- 结算:先分出胜负的一方弹卡片并发 `done`,锁步照跑到两边都分出(开着光速延迟时赢的一方要等看见沉没的光),主机再收尾(最后一段带 `end`)。对手离开 = 锁步结束、状态条提示。
